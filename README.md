# PosDemoApp - شاشة تجريبية كاملة (WinForms حقيقي)

مشروع **جاهز للفتح مباشرة في Visual Studio** (وليس مجرد مقتطف كود). افتح `PosDemoApp.csproj` وستجد `SamplePosForm.cs` يظهر تصميمه في قناة التصميم (Designer) بشكل طبيعي مع كل الأدوات.

## طريقة التشغيل
1. افتح `PosDemoApp.csproj` في Visual Studio (2019 أو أحدث، يدعم .NET Framework 4.8).
2. افتح `SamplePosForm.cs` بزر الفأرة الأيمن ثم **View Designer** لرؤية الشاشة تصميميًا.
3. اضغط F5 للتشغيل مباشرة.

## محتويات الشاشة
- **مجموعة إعدادات الاتصال**: اختيار طابعة محلية (تفعّل حقل اسم الطابعة) أو طابعة شبكية (تفعّل حقلي IP والمنفذ) - يتم تفعيل/تعطيل الحقول تلقائيًا حسب الاختيار.
- **مجموعة إعدادات الورق**: 58مم / 80مم، وخيار القص التلقائي.
- **زر "معاينة الفاتورة"**: يعرض صورة الفاتورة كما ستُطبع فعليًا داخل الشاشة (بدون طباعة حقيقية).
- **زر "طباعة فاتورة تجريبية"**: يطبع فعليًا (محليًا أو شبكيًا حسب الاختيار) بفاتورة بالبيانات التجريبية نفسها من الفاتورة النموذجية ثنائية اللغة.
- **زر "اختبار القص"**: يرسل أمر قص فقط للتأكد أن الطابعة تدعمه.
- **زر "اختبار الاتصال بالشبكة"**: يتحقق من الوصول للطابعة الشبكية بدون طباعة (مفعّل فقط عند اختيار "طابعة شبكية").
- **شريط حالة أسفل الشاشة**: يعرض نجاح/فشل كل عملية برسالة واضحة بدل أي كراش.

## لتجربتها فورًا على طابعتك
افتح `SamplePosForm.cs` وعدّل القيم الافتراضية في `SamplePosForm_Load`:
```csharp
txtPrinterName.Text = "XP-80C";      // اسم طابعتك المحلية كما في ويندوز
txtIp.Text = "192.168.1.50";         // عنوان IP طابعتك الشبكية
```
ثم شغّل التطبيق، اختر نوع الاتصال، واضغط "معاينة الفاتورة" أولًا للتأكد من الشكل قبل الطباعة الفعلية.

## ملاحظة
هذا المشروع يحتوي على نسخة من كل ملفات مكتبة `ThermalReceiptPrinter` (نفس الأصناف: `PrinterProfile`, `ReceiptModel`, `ReceiptPrinter`... إلخ) مدمجة مباشرة فيه ليعمل كتطبيق مستقل بدون أي إعداد مراجع إضافي. إذا أردتها لاحقًا كـ Class Library منفصلة تُستخدم من أكثر من مشروع، أخبرني وأُعيد فصلها مع مرجع مشروع (Project Reference) بينهما.
